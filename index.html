01About

在代码里，
慢慢长出自己

你好，我是李成豪。2023 年注册了这个 GitHub 账号，同年 12 月写下第一版 index.html，把它放到了网上。那时候页面很简陋，但第一次看见自己的名字出现在浏览器地址栏里，那种感觉记得很清楚。

之后断断续续地折腾：试过用 Python 做《跳一跳》的辅助脚本，第一次摸到 图像识别和自动化；也反复重构过自己的主页，想让它更接近心里那个样子。 我不是科班出身的"技术大牛"，更像是一个愿意把想法真正做出来的人—— 想到什么，就去写，写坏了再改。

现在我在把前端这块补扎实：布局、动效、可访问性，一样一样来。这个页面就是最新的答案。

04Journey

一路上留下的脚印

2023.10

注册 GitHub，第一次敲下 git push

开了自己的账号，把这些年零散的代码正式放到线上。当时还不知道 README 要写什么。

2023.12

第一版个人主页上线

手写了一个 index.html，用了暗色背景和一张卡片。虽然只是几十行 CSS，但那是自己的第一个"网站"。

2026.10

重新开始，连续几天都有提交

从 hello-world 重新热身，接着是 test_1、test_2——不再纠结"要做个完美的项目"，先把东西做出来再说。
